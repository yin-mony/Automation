# 匹配回填工具使用说明

## 项目是什么

本项目是一个 Excel 匹配回填工具，用于把多个店铺副表中的 `ASIN` 按订单编号匹配到主表，并回填到主表的编码列。

典型场景是：主表里已经有各店铺的 AWD 费用记录，但 `编码（必填）` 或 `编码(必填)` 列缺少 ASIN；副表里有订单编号与 ASIN 明细。工具会按订单编号对齐两边数据，把匹配到的 ASIN 写回主表。

## 项目干什么

工具会完成以下流程：

1. 读取主表 Excel。
2. 读取一个或多个副表 Excel。
3. 用主表 `描述` 列和副表 `多年期定价订单编号` 列做完全匹配。
4. 读取匹配行对应的副表 `ASIN`。
5. 同一个订单编号匹配到多个 ASIN 时，去重后用英文逗号 `,` 拼接。
6. 将结果写入主表 `编码（必填）` 列；如果主表只有 `编码(必填)`，则写入该列。

兼容旧版副表表头：

| 新版字段 | 旧版兼容字段 | 用途 |
| --- | --- | --- |
| `多年期定价订单编号` | `myp_order_id` | 与主表 `描述` 做匹配 |
| `ASIN` | `asin` | 回填到主表编码列的值 |

## 怎么操作

### 方式一：双击启动 GUI

适合日常使用。

1. 双击 `run_gui.bat`。
2. 等待依赖安装或检查完成。
3. 在界面中选择主表文件。
4. 在界面中选择一个或多个副表文件。
5. 点击“开始执行”。
6. 等待完成弹窗。
7. 回到主表查看编码列回填结果。

注意：GUI 模式默认直接写回所选主表。运行前建议先备份主表；如果主表正在 Excel 中打开，可能会因为文件占用导致写入失败。

### 方式二：命令行交互模式

适合不想打开 GUI、或需要在终端中执行。

```bash
python run.py --mode cli
```

按提示依次输入：

1. 主表路径。
2. 副表路径；多个副表每行输入一个，输入空行结束。
3. 输出主表路径；留空则覆盖原主表。

### 方式三：直接运行主逻辑文件

适合调试或临时命令行调用。

```bash
python main.py <主表路径> <副表1路径> [副表2路径 ...]
```

直接运行 `main.py` 时，如果不传命令行参数，会使用文件底部 `config` 字典中的示例路径。正式使用前需要把 `config["totalPath"]` 和 `config["subPaths"]` 改成真实文件路径。

## 输入文件要求

### 主表要求

主表必须包含：

| 列名 | 是否必需 | 说明 |
| --- | --- | --- |
| `描述` | 必需 | 用于和副表订单编号完全匹配 |
| `编码（必填）` | 推荐 | 优先写入的目标列 |
| `编码(必填)` | 兼容 | 如果没有 `编码（必填）`，则写入该列 |

如果主表同时没有 `编码（必填）` 和 `编码(必填)`，工具会自动新增 `编码（必填）` 列。

### 副表要求

新版副表必须包含：

| 列名 | 是否必需 | 说明 |
| --- | --- | --- |
| `多年期定价订单编号` | 必需 | 与主表 `描述` 做完全匹配 |
| `ASIN` | 必需 | 匹配成功后回填到主表编码列 |

旧版副表仍可使用 `myp_order_id` 和 `asin`。

## 匹配与回填规则

- 匹配方式：去除前后空格后完全匹配。
- 匹配方向：主表 `描述` 匹配副表订单编号。
- 多个副表：按选择或输入顺序依次处理。
- 同一个订单编号多个 ASIN：去重，保留首次出现顺序，用英文逗号拼接。
- 第一个副表：按匹配结果写入编码列。
- 第二个及后续副表：在已有编码基础上追加新 ASIN，并避免重复追加。

## 配置信息

本项目没有单独的外部配置文件。主要配置集中在 `main.py` 的 `ExcelFile` 初始化参数，以及 `main.py` 底部直接运行时使用的 `config` 字典。

### `ExcelFile` 默认配置

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `path` | `None` | 可选主表路径，便于旧式调用 `ExcelFile(主表路径).run(副表路径)` |
| `totalCol` | `描述` | 主表匹配列 |
| `findCol` | `多年期定价订单编号` | 副表匹配列 |
| `asinCol` | `ASIN` | 副表取值列 |
| `targetCol` | `编码（必填）` | 主表优先写入列 |
| `altTargetCol` | `编码(必填)` | 主表兼容写入列 |
| `legacyFindCols` | `("myp_order_id",)` | 旧版副表匹配列兼容名 |
| `legacyAsinCols` | `("asin",)` | 旧版副表取值列兼容名 |
| `separator` | `,` | 多个 ASIN 拼接分隔符 |

### `main.py` 直接运行配置

`main.py` 文件底部有一个 `config` 字典：

```python
config = {
    "totalPath": r"C:\RPA流程\...\主表.xlsx",
    "subPaths": [
        r"C:\RPA流程\...\副表.xlsx",
    ],
}
```

这只在直接运行 `python main.py` 且没有传命令行参数时使用。日常 GUI 操作不依赖这个配置。

### 输出配置

| 运行方式 | 输出位置 |
| --- | --- |
| GUI 模式 | 默认覆盖所选主表 |
| CLI 模式 | 可输入输出路径；留空则覆盖原主表 |
| `main.py` 命令行参数模式 | 默认覆盖传入主表 |

## 常见问题

### 提示找不到列

检查主表和副表表头是否与要求一致，并确认表头没有多余空格。工具会自动去除列名前后空格，但不会模糊匹配不同含义的列名。

### 写入失败

通常是主表正在 Excel 中打开。关闭主表后重新执行。

### 匹配结果为空

检查主表 `描述` 和副表 `多年期定价订单编号` 是否属于同一批订单。两列必须完全相同才会匹配成功。

### 多个副表回填有重复 ASIN

工具会对同一订单编号下的 ASIN 去重，也会在多个副表依次回填时避免重复追加。
