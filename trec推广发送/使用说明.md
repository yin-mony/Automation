# TREC 推广发送使用说明

## 项目用途

本子项目负责执行“trec公司+个人合作推广”上游项目产生的推广发送流程。

当前正式流程只保留邮件发送模式：读取公司/个人搜索匹配结果表中的“邮箱”列，按固定邮件模板发送推广邮件，并在后台保存邮件发送记录。

## 文件职责

| 文件 | 作用 |
| --- | --- |
| `run.py` | GUI 窗口入口，只负责运行环境选择、文件选择、只读展示邮件配置、发送按钮和日志展示。 |
| `main.py` | 正式流程逻辑文件，负责读取文件、提取邮箱、生成邮件、发送邮件和保存后台记录。 |
| `test.py` | 测试专用文件。未得到同步 main 文件授权前，测试逻辑只允许在这里实现。 |
| `assets/time2renew-logo.png` | 邮件签名底部内嵌 Logo 图片。 |
| `output/邮件发送记录.xlsx` | 后台发送记录，用于排查每封邮件的来源行、发送状态和失败原因。 |

## 默认读取文件

默认从上游项目读取以下两个固定结果表：

```text
C:\Users\admin\Desktop\Automation\trec公司+个人合作推广\output\已完成搜索匹配的个人联系信息数据.xlsx
C:\Users\admin\Desktop\Automation\trec公司+个人合作推广\output\已完成搜索匹配的公司联系信息数据.xlsx
```

程序只读取表头为“邮箱”的数据列。没有邮箱的行会自动跳过，不再执行短信模式或全部模式。

## 默认配置来源

默认配置统一写在 `main.py` 的 `Main.defaultConfig()` 中，GUI 会直接读取这里的配置。

运行环境 `isOnline` 与其他子项目保持一致：

- 本机：用于本地电脑调试和人工验证。
- 线上：用于正式或服务器环境运行。

当前发送流程会把运行环境写入后台邮件发送记录，便于后续排查发送来源。

SMTP 发件邮箱、服务器、端口、用户名和授权码属于固定系统参数，只允许在 `main.py` 中维护。GUI 可以只读展示这些参数，但不允许修改。

运行时配置合并规则：

```python
config = Main.defaultConfig()
config.update(外部传入配置)
Main(config).run(executeSend=True, sourceFiles=文件列表)
```

## 启动方式

推荐使用 GUI：

```bash
python run.py
```

也可以运行正式流程的 dry run：

```bash
python main.py
```

`python main.py` 默认只生成后台发送记录，不真实发送邮件。

## 邮件内容

邮件主题写入邮件客户端 Subject 字段，不放入正文。

正文固定包含推广内容、`Qian Yi` 和 `Ho` 两行署名，以及底部签名：

```text
Time2renew Support Team

Website: time2renew
```

Logo 图片通过邮件 HTML 的 CID 内嵌方式放在签名下方。
