# 下载亚马逊后台站点报告

易得客浏览器自动化：登录易得客并进入指定店铺环境，打开 Amazon/TikTok 卖家后台，优先切换为中文页面语言，再切换到指定亚马逊后台站点，并在 Reports Repository 请求指定月度报告。

## 当前能力

- `run.py`：复刻 FBA 子项目易得客流程页的 Tkinter GUI 入口，包含公共配置、易得客流程配置、报告请求配置、运行日志与后台线程。
- `main.py`：主业务逻辑，负责易得客登录/按店铺站点进店、Amazon 后台登录确认、站点切换、中文语言切换、报告表单选择与 Request Report。
- `YidekeLogin.py`：基于 `FBA货件差异自动索赔` 子项目易得客登录逻辑整理的通用登录文件，已按全局命名规范调整。
- `test.py`：测试专用入口，默认只展示配置和支持项，不启动浏览器。

## 报告类型

| GUI 文案 | 后台报告值 | 说明 |
| --- | --- | --- |
| `汇总报告` | `SELLER_SUMMARY_DATE_RANGE` | 对应 Amazon 后台 Summary 报告类型 |
| `Transaction 报告` | `SELLER_TRANSACTION_DATE_RANGE` | 对应 Amazon 后台 Transaction 报告类型 |

当前流程以点击 **Request Report / 请求报告** 为完成边界，不持续等待报告生成或下载。

## 站点切换模式

| GUI 文案 | 说明 |
| --- | --- |
| `单站点自主切换模式` | 只请求 `Amazon 后台站点` 中指定的一个亚马逊后台站点，适合原“下载美国站 Transaction 报告”一类单站点场景 |
| `全站点自动切换模式` | 按 `全站点范围` 中勾选的站点逐个切换并请求报告，默认全选，适合原“下载全站点汇总报告”场景 |

报告类型和站点切换模式是两个独立配置：例如可以选择 `汇总报告 + 全站点自动切换模式`，也可以选择 `Transaction 报告 + 单站点自主切换模式`。

## GUI 字段说明

| 字段 | 说明 |
| --- | --- |
| `运行环境` | `线上` 会先登录易得客管理端并点击访问店铺；`线下` 会跳过管理端登录，直接启动本机店铺 profile |
| `易得客账号 / 易得客密码` | 易得客客户端登录账号 |
| `店铺站点` | 易得客管理端中店铺所在站点区域，用于按站点和店铺 IP 点击访问 |
| `店铺 IP / 店铺端口` | 用于定位店铺 profile 和 DrissionPage 调试端口；多个值可用逗号或换行分隔 |
| `Amazon 邮箱 / Amazon 密码` | 复用 FBA 子项目 `YidekeLogin.py` 中的 Amazon Seller Central 登录确认逻辑；密码可留空，留空时会尝试浏览器已保存密码或人工确认 |
| `Amazon 后台站点` | `单站点自主切换模式` 下生效；也会作为 Amazon 登录/账号选择时的目标后台站点 |
| `报告类型` | 选择 `汇总报告` 或 `Transaction 报告` |
| `站点切换模式` | 区分只处理一个站点，还是按勾选范围自动逐个切换站点 |
| `全站点范围` | `全站点自动切换模式` 下生效，默认全选，可按需要取消部分站点 |

## Amazon 后台登录逻辑

本项目复用 FBA 子项目的 Amazon 登录处理思路，并在 `YidekeLogin.py` 中通过 `YidekeLogin.AmazonSeller` 执行登录确认。流程在接管店铺浏览器后会先确认 Amazon Seller Central 登录态，必要时处理密码页、二步验证码插件和账号选择页；完成后再优先切换中文页面语言，并进入报告请求逻辑。

店铺 profile 启动时会按易得客“访问”窗口的方式进入 loading 环境检测页，并携带 `shopId`、站点 `region` 和 Seller Central 跳转地址。若易得客返回网络出口、线路优化或浏览器自检失败，流程会在进入报告请求前停止，并把易得客页面中的失败原因写入日志，避免误判为 Amazon 登录成功。

## 支持站点

当前站点列表参考 FBA 子项目的完整站点映射，包含美国、加拿大、墨西哥、巴西、英国、法国、德国、意大利、西班牙、荷兰、瑞典、波兰、比利时、爱尔兰、日本、新加坡、澳大利亚、印度、阿联酋、沙特阿拉伯、土耳其、埃及、南非。

## 运行

```bash
python run.py
```

测试入口：

```bash
python test.py
```

`test.py` 默认不启动真实浏览器；需要真实测试时，在文件内填写测试配置并把 `runBrowser` 改为 `True`。

## 依赖

- Python 3
- DrissionPage
- psutil
- pywinauto

## 注意事项

- 原 `下载全站点汇总报告` 和 `下载美国站Transaction报告` 子项目仅作为只读参考，本项目不修改旧目录。
- 后台语言会优先切换为中文，但部分控件值仍使用 Amazon 页面自身的固定英文 `value`。
- 若某个站点不支持某类报告，页面下拉选项可能不存在，流程会在选择报告类型时报错并写入日志。
