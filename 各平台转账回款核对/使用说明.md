# 各平台转账回款核对使用说明

## 一、功能说明

本工具用于从赛狐 ERP 下载 TikTok、eBay、Walmart、亚马逊四个平台的转账明细，并将四个平台数据合并后与收款流水进行到账核对。

工具提供两个独立操作：

- **下载文件**：只下载当前选择的平台明细。
- **表格文件数据处理**：不打开浏览器，直接处理已经下载完成的四个平台文件。

## 二、启动程序

运行项目目录中的 `run.py`，打开“各平台转账回款核对”窗口。

界面包含：

- 执行日期
- 输出目录
- 收款流水文件
- 平台模式
- 流程页面
- 下载文件按钮
- 表格文件数据处理按钮

## 三、填写执行信息

### 1. 执行日期

分别选择开始日期和结束日期。

日期会用于赛狐页面筛选以及下载文件命名。建议四个平台使用完全相同的日期范围。

### 2. 输出目录

点击“选择”，设置四个平台源文件和最终处理结果的保存目录。

建议每个核对月份使用单独的空目录，避免程序读取到其他月份的旧文件。

### 3. 收款流水文件

点击“上传”，选择需要核对的收款平台流水记录 Excel 文件。

流水文件至少需要包含以下字段：

| 字段 | 说明 |
| --- | --- |
| 收款平台 | 实际收款平台 |
| 收款时间 | 实际到账日期 |
| 收款币种 | USD、GBP、JPY、CAD 等币种代码 |
| 收款金额 | 实际到账金额 |

下载平台文件时可以暂不上传流水文件；执行“表格文件数据处理”前必须上传。

## 四、下载四个平台文件

一次只能下载当前选择的一个平台文件。请按以下顺序分别执行。

### 1. 下载 TikTok

1. 平台模式选择“多平台”。
2. 流程页面选择“TikTok”。
3. 点击“下载文件”。
4. 等待“文件下载完成”提示。

### 2. 下载 eBay

1. 平台模式选择“多平台”。
2. 流程页面选择“eBay”。
3. 点击“下载文件”。
4. 等待“文件下载完成”提示。

### 3. 下载 Walmart

1. 平台模式选择“多平台”。
2. 流程页面选择“Walmart”。
3. 点击“下载文件”。
4. 等待“文件下载完成”提示。

Walmart 按付款周期筛选。付款周期可能从当月开始并在下月结束，这是正常情况。

### 4. 下载亚马逊

1. 平台模式选择“亚马逊”。
2. 流程页面选项会自动禁用，无需选择。
3. 点击“下载文件”。
4. 等待“文件下载完成”提示。

下载过程中不要关闭自动打开的浏览器，也不要手动切换赛狐页面。

## 五、执行表格文件数据处理

确认输出目录中已经存在以下 4 个源文件：

- TikTok 转账明细
- eBay 转账明细
- Walmart 转账明细
- 亚马逊转账明细

然后执行：

1. 确认输出目录选择正确。
2. 上传收款流水文件。
3. 确认日期与下载文件所属月份一致。
4. 点击“表格文件数据处理”。
5. 等待“表格文件数据处理完成”提示。

表格处理期间不会打开赛狐页面或浏览器。

## 六、处理结果

完整流程最终会在输出目录生成 7 个文件：

1. TikTok 转账明细源文件
2. eBay 转账明细源文件
3. Walmart 转账明细源文件
4. 亚马逊转账明细源文件
5. Walmart 汇总完成文件
6. 各平台回款明细表
7. 各平台回款明细表（对账结果）

### 各平台回款明细表

这是四个平台初次合并后的基础数据，到账状态统一为“暂无匹配”。该文件不会被后续对账覆盖。

### 各平台回款明细表（对账结果）

这是使用收款流水核对后的新文件：

- 匹配成功：到账状态为“已到账”。
- 未匹配成功：到账状态为“暂无匹配”。

## 七、到账核对规则

平台回款与收款流水需要同时满足以下条件：

- 币种相同。
- 金额相同。
- 收款日期在平台转账日期当天至之后 5 天内。

一条收款流水只会匹配一条平台回款记录。

## 八、注意事项

- 四个平台必须使用相同的输出目录。
- 四个平台建议使用相同的执行日期。
- 表格处理前不要修改下载文件的字段名称。
- 不要删除或覆盖平台源文件。
- 不要同时打开即将生成的结果文件。
- 如果文件正在 WPS 或 Excel 中打开，程序可能提示没有文件写入权限。
- 输出目录存在多个历史月份文件时，程序会选择符合命名规则且更新时间最新的文件，建议使用空目录执行。

## 九、常见问题

### 提示缺少平台转账明细文件

检查四个平台文件是否都已下载到当前输出目录，文件名是否被手动修改。

### 提示 DLL load failed 或 onnxruntime 错误

请使用项目的 `run.py` 启动程序，不要直接从其他脚本启动 GUI。

### 提示 PermissionError

关闭 WPS 或 Excel 中已打开的 Walmart 汇总文件、合并明细或对账结果，再重新点击“表格文件数据处理”。

### 下载按钮执行后没有文件

检查赛狐是否登录成功、页面筛选日期是否正确、浏览器下载是否被拦截，以及输出目录是否有写入权限。
