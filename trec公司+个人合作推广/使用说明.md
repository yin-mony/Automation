# 使用说明

## 一、准备环境

在项目目录执行：

```powershell
py -3.14 -m pip install -r requirements.txt
```

安装内容包括 PySide6、DrissionPage、openpyxl、pproxy 和 PySocks。

## 二、初始化配置

1. SerpApi Key、阿里邮箱账号和授权码集中在 `Main.__init__` 的默认参数中。
2. `config.local.json` 为可选覆盖配置，字段参考 `config.example.json`。
3. 当前代理继续使用 `ipfiy.py`；若 `proxyUrl` 留空，程序会用 AST 读取其中的 `set_proxy` 参数，不会执行该文件的测试代码。

界面只显示“已配置/未配置”，不会显示账号、授权码或 API Key。由于默认凭据位于源码中，提交或分享项目前必须清除或更换。

## 三、启动界面

```powershell
py -3.14 run.py
```

### 工作台

- 查看五个流程阶段的当前状态。
- 查看 SerpApi 剩余额度和今日用量。
- 启动后自动刷新官方账号额度；例如账号已用 33 次时显示剩余 217 / 250。
- 查看本地 TREC 数据量和最后同步时间。
- 查看待审核数量。
- 刷新官方额度、同步 TREC 或打开输出目录。

### 运行设置

- “每日新搜索上限”可以直接输入或用上下箭头调整，默认 6 次。
- 点击“保存运行设置”后写入本机 `config.local.json`，下次启动继续使用。
- `公司 + 个人`：目标各 10 个，搜索上限在两种对象间自动分配；奇数时多出的 1 次分给公司。
- `仅公司`：目标 10 个，全部每日新搜索额度用于公司。
- `仅个人`：目标 10 个，全部每日新搜索额度用于个人。
- 可选择运行前增量同步 TREC。
- 普通网站进入二级页面提取公开联系方式；Facebook 永远只保存主页链接。
- 切换三个模式时，每日目标、候选规则、额度分配、数据处理范围和输出文件会同步变化。

公司/个人批次数量和月末预留线仍由 `Main.__init__` 控制；每日新搜索上限在 GUI 中开放修改。实际搜索还会受 SerpApi 官方剩余额度和月末预留线限制。

### 任务监控

- `暂停`：当前安全点暂停。
- `继续`：恢复当前任务。
- `安全停止`：完成当前安全步骤后退出，已经写入 `data.db` 的结果不会丢失。

普通网站遇到验证码或人机验证时，程序会暂停并保留可见浏览器。人工处理完成后点击“已完成，继续”。

### 邮件设置

1. 邮件模式为单选，默认“生成邮箱草稿”。
2. 填写或确认阿里邮箱账号、第三方客户端安全密码、邮件主题和正文。
3. “生成邮箱草稿”通过 IMAP 写入阿里邮箱服务器草稿箱，不是本地缓存。
4. “真实发送”通过 SMTP 立即发出，执行前会再次显示确认窗口。
5. 页面显示本次可处理、重复跳过、历史草稿、历史发送和唯一联系人数量。
6. 页面显示正文 Logo 加载状态；`file/time2renew-logo.png` 会以内嵌图片加入服务器草稿和真实邮件。

阿里邮箱管理员必须允许第三方客户端，并为账号开启 IMAP/SMTP。端口使用 IMAP SSL 993 和 SMTP SSL 465。

Logo 使用 CID 内嵌，不依赖收件人访问外部图片网址；纯文本邮件客户端仍会显示不带图片的备用正文。

### 结果审核

1. 使用状态下拉框查看待审核、已通过、已拒绝或全部记录。
2. 可以选择一条、多条，或勾选“全选当前列表”。
3. 全选只作用于当前筛选结果，不会选择被筛选隐藏的记录。
4. 核对对象名、联系方式、来源链接和置信度。
5. 将所选记录批量设置为“通过”“拒绝”或“待审核”。
6. 点击“进入邮件设置”，选择服务器草稿或真实发送。

只有“已通过”的邮箱才能进入邮件处理；页面会实时显示当前已选择的记录数量。

### 操作说明

- 该页面按工作台、运行设置、任务监控、邮件设置、结果审核、结果数据、连接状态逐项说明操作。
- 推荐首次使用前完整查看一次，后续可按页面名称快速核对注意事项。
- 说明页只展示文字，不会启动任务、修改审核状态或发送邮件。

### 结果数据

- 查看已经保存的公司和个人结果。
- 单独查看、选择和复制 Facebook 主页链接。
- 打开中文 Excel 结果所在目录。

### 连接状态

该页面显示每个服务的网络路径：TREC、SerpApi、普通网页和 SMTP 默认直连，Facebook 不发起页面请求。

## 四、首次运行

1. 点击“刷新状态”，确认 SerpApi Key、直连模式和 DrissionPage 可用。
2. 点击“同步 TREC”。首次同步是全量，后续按 `updated` 字段增量同步。
3. 先选择单一模式完成 1 个公司或 1 个个人的验收。
4. 检查 `data.db`、中文 Excel、来源链接和人工审核记录。
5. 公司与个人都通过验收后，再恢复每日目标运行。

## 五、网页网络方式

默认使用直接访问：

1. `proxyRequired=false` 时不读取或测试 `ipfiy.py`。
2. DrissionPage 直接打开普通二级页面。
3. Facebook 仍然只保存链接，不打开页面。

代理代码仍然保留。以后确实需要代理时，可在 `config.local.json` 中把 `proxyRequired` 改为 `true`；此时才会启用 SOCKS5 多目标检测、本地 HTTP 桥和出口一致性验证。

## 六、Facebook 链接

- 从 SerpApi 搜索结果和普通网站外链中识别 Facebook 主页。
- 不登录 Facebook，不打开 Facebook 页面，不进行抓包或联系方式提取。
- 链接写入 `data.db`、GUI“结果数据”页和公司/个人 Excel 文件。

## 七、常见问题

### 提示“SerpApi Key 未配置”

检查 `Main.__init__` 的 `serpapiKey` 默认参数、`config.local.json` 覆盖值或环境变量 `TREC_SERPAPI_KEY`。

### 为什么不再检测代理

当前默认是直接访问，代理节点不会参与完整流程，也不会阻断任务。

### 如何重新启用代理

将 `config.local.json` 中的 `proxyRequired` 改为 `true`。启用后若出口验证失败，程序仍会停止并禁止直连。

### 当天完成数量低于目标

先查看工作台的当天已用次数、运行设置中的每日新搜索上限和 SerpApi 官方剩余额度。剩余目标会保留在数据库中，后续日期继续处理。

### 为什么联系人不会重复发送

对象、搜索缓存和邮箱分别去重。成功创建草稿或真实发送后，邮箱和动作会写入 SQLite `mail_actions`；后续运行会显示为“重复跳过”。

### 如何运行 EXE

双击 `dist/TREC推广工具/TREC推广工具.exe`。必须整体保留 `TREC推广工具` 目录，不能把 EXE 与 `_internal`、`ipfiy.py`、`config.local.json` 和 `output/data.db` 分开。

发布目录含代理及账号配置，只能存放在可信设备，不要直接上传或分享。
