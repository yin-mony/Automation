# TREC 公司+个人合作推广更新说明

## 2026-08-06

### 本次调整

1. 搜索流程改为 SerpApi Google 搜索接口。
   - 不再打开 Google 页面手动搜索。
   - 每个搜索对象调用 1 次 `https://serpapi.com/search`。
   - 固定读取 Google 第一页自然结果，不写死 `num` 数量。

2. 二级页面抓取保留浏览器流程。
   - SerpApi 只提供搜索结果文本、标题、摘要和链接。
   - 程序继续用 DP 浏览器打开 `organic_results.link`。
   - 邮箱和电话仍从二级页面正文中提取。

3. 公司模式和个人模式合并回 `main.py`。
   - 公司模式由 `companyMode()` 负责。
   - 个人模式由 `personMode()` 负责。
   - 公共配置统一放在 `Main.__init__()`。
   - `run.py` 只负责 GUI 配置、模式选择、开始运行和日志展示。

4. 取消过多搜索配置。
   - 取消公司/个人模式处理总上限。
   - 取消公司/个人模式开关配置。
   - 取消搜索起始位置配置。
   - 取消 SerpApi 返回结果数配置。
   - 公司模式、个人模式每次固定处理 10 个搜索对象，断点自动续跑。

5. 数据源固定为内置清洗表。
   - `file` 是内置数据目录，不可在 GUI 修改。
   - 当前搜索流程固定读取 `file/已获取到的初始总数据.xlsx`。
   - `file/初始总量数据未清洗.xlsx` 作为全量未清洗底表和邮件附件保留。
   - TREC 网站重新采集流程已在 `main.py` 注释保留，不作为当前默认流程执行。

6. 邮箱和电话增加清洗过滤。
   - 过滤 `admin@`、`info@`、`contact@` 等公共邮箱。
   - 过滤 `.gov`、`.mil`、`.edu` 等政府、军事、学校邮箱。
   - 过滤包含军警、学校、公共机构特征的域名。
   - 过滤明显占位电话和异常电话。

7. 邮件发送流程调整。
   - `email_util.py` 只负责最终结果附件通知邮件。
   - 推广邮件发送流程保留在 `main.py` 的推广发送函数中。
   - 推广发送开关只保留 `promotionExecuteSend`。
   - `false` 只生成后台发送记录，`true` 才真实发送推广邮件。

8. GUI 调整。
   - 顶部只保留一个“开始运行”按钮。
   - 左侧保留配置、采集初始数据、公司模式、个人模式。
   - 配置页统一放公共配置。
   - 配置页包含保存配置和恢复默认按钮。
   - 安全验证配置已取消旧浏览器搜索依赖，当前 SerpApi 搜索不需要 Google 人工验证配置。

### 凭证处理说明

本项目需要以下 3 个敏感凭证：

| 环境变量 | 作用 |
| --- | --- |
| `TREC_SERPAPI_KEY` | SerpApi 搜索接口 Key。 |
| `TREC_RESULT_SMTP_AUTH_CODE` | 最终结果附件通知邮件 SMTP 授权码。 |
| `TREC_PROMO_SMTP_AUTH_CODE` | 推广邮件真实发送 SMTP 授权码。 |

这些凭证不以明文提交到远端仓库。需要本机明文运行时，请在本机系统环境变量里配置，程序会自动读取。

### 输出文件

当前项目最终只关注 4 个数据表：

| 文件 | 说明 |
| --- | --- |
| `file/初始总量数据未清洗.xlsx` | TREC 网站全量未清洗原始底表。 |
| `file/已获取到的初始总数据.xlsx` | 已清洗后的全量初始数据。 |
| `output/已完成搜索匹配的公司联系信息数据.xlsx` | 公司模式搜索匹配结果。 |
| `output/已完成搜索匹配的个人联系信息数据.xlsx` | 个人模式搜索匹配结果。 |

### 运行注意

1. 正式搜索前必须确认 `file/已获取到的初始总数据.xlsx` 存在。
2. `outputDir` 不允许配置为 `file`。
3. SerpApi 免费额度有限，每次运行固定处理 10 个对象。
4. 如需从头重新搜索，需要删除对应模式的断点文件和缓存文件。
5. 推广邮件测试时保持 `promotionExecuteSend = false`，确认记录无误后再改为 `true`。
