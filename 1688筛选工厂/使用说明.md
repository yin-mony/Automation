# 1688筛选工厂使用说明

## 项目用途

本项目用于根据本地商品图片在1688进行以图搜款，筛选真实工厂认证的商品和店铺，并将整理后的结果导出为Excel表格。

程序会自动完成图片上传、筛选条件设置、商品与店铺信息采集、工厂优先级判断、结果去重和Excel排版。进入图片搜索结果页后，需要人工调整商品主体的裁剪范围并点击确认。

## 使用前准备

1. 安装Python，并确保可以正常启动Chrome或Chromium浏览器。
2. 在项目目录安装运行依赖：

```powershell
pip install DrissionPage openpyxl Pillow
```

3. 准备一个图片目录，将同一种材质的商品图片放在该目录中。
4. 图片目录名称会作为材质名称写入结果表，例如：

```text
file/
└── 不锈钢镀金/
    ├── 1.jpg
    └── 2.png
```

支持的图片格式为 `.jpg`、`.jpeg`、`.png`、`.bmp` 和 `.webp`。

## 配置说明

打开 `run.py`，根据实际情况修改 `config`：

```python
config = {
    "folderPath": "./file/不锈钢镀金",
    "outputDir": "",
    "outputFileName": "1688筛选工厂结果.xlsx",
    "cropTimeout": 300
}
```

- `folderPath`：待搜索图片目录，目录名会作为材质名称。
- `outputDir`：结果表输出目录。留空时输出到图片目录的上一级目录。
- `outputFileName`：最终导出的Excel文件名。
- `cropTimeout`：等待人工完成主体框选的最长秒数，默认300秒。

## 启动程序

在当前子项目目录执行：

```powershell
python run.py
```

程序会启动浏览器并打开1688。如果页面要求登录，请先在浏览器中完成登录，再继续操作。

## 操作流程

1. 程序读取配置目录中的全部图片。
2. 程序打开1688首页，上传当前图片并点击“搜索图片”。
3. 进入搜索结果页后，程序自动点击“框选主体”并暂停等待。
4. 在弹出的裁剪界面中，手动调整选区，使选区尽量只包含需要搜索的商品主体。
5. 点击裁剪界面的确认按钮。程序检测到搜索结果刷新后自动继续。
6. 程序勾选“真实工厂认证”，输入图片目录对应的材质名称并采集结果。
7. 当前图片处理完成后，程序继续处理下一张图片；每张图片都需要重复一次主体框选和确认操作。
8. 全部图片完成后，程序自动清洗、排序并导出Excel结果表。

## 筛选与优先级

程序会排除公司名称中包含“电子商务”“贸易”或“商贸”的结果，并按照以下优先级排列工厂：

- `P0`：超级工厂。
- `P1`：源头旗舰或实力商家。
- `P2`：普通商家。

同一图片下重复的公司、门店和商品链接会在导出前进行去重。同等级、同公司、同门店的多条商品记录会在结果表中合并显示工厂和门店信息。

## 输出结果

程序会直接新建Excel文件，不使用模板文件，也不依赖本机安装Microsoft Excel。

结果表包含以下字段：

| 主图（自填） | 材质（自填） | 1688链接 | 工厂名称 | 门店链接 | 优先级排序 |
| --- | --- | --- | --- | --- | --- |

结果表会保留固定的表头、列宽、行高、边框、图片、合并单元格和文字排版规则。

## 常见情况

- 提示“路径不存在”：检查 `folderPath` 是否填写正确，并确认从子项目目录启动程序。
- 提示“没有找到图片”：确认目录中存在受支持格式的图片。
- 提示未找到“框选主体”按钮：可能是1688页面尚未加载完成或页面结构发生变化，可重新运行后确认页面状态。
- 提示等待人工确认超时：在 `cropTimeout` 指定时间内完成裁剪并点击确认，或适当增大该配置值。
- 图片插入失败：确认原图片文件未被移动、删除或损坏，并确认已经安装 `Pillow`。
