# FBA 货件差异自动索赔使用说明

本文档面向实际操作人员，说明如何通过 GUI 运行赛狐流程和易得客流程。

## 一、运行前准备

1. 确认电脑为 Windows 系统。
2. 确认已安装 Chrome 或 Edge。
3. 如需从 DOCX 模板生成 PDF，确认电脑已安装 Microsoft Word。
4. 如需运行易得客流程，确认易得客客户端可正常启动并可打开店铺浏览器。
5. 确认项目目录中存在以下内置文件：
   - `服务商模板.docx`
   - `AWD_POD.pdf`
   - `FBA_POD.pdf`

## 二、启动程序

源码方式启动：

```bash
python run.py
```

exe 方式启动：

```text
双击 dist/FBA货件差异自动索赔.exe
```

如果是发给其他人使用，建议发送整个 `dist` 文件夹，保证 exe 和 `run_config.json` 在同一目录。

## 三、公共配置说明

公共配置位于 GUI 顶部，两个流程共用。

| 配置项 | 说明 |
| --- | --- |
| 运行环境 | 选择线下或线上，传入流程用于区分运行环境。 |
| 邮件通知 | 控制是否发送邮件。当前赛狐流程可发送 POP 文件；易得客流程可发送 CASE 结果汇总。 |
| 接收邮箱 | 开启邮件通知后必填。 |
| 企业微信通知 | 控制是否发送企业微信群机器人通知。 |
| 企业微信 Webhook | 群机器人 Webhook 地址。 |
| @ 手机号 | 企业微信消息中需要 @ 的手机号，可填写一个或多个。 |

配置会保存到 `run_config.json`。如果配置异常，可以删除该文件，程序下次启动会使用 `main.py` 中的默认配置重新回填。

## 四、赛狐流程使用步骤

赛狐流程负责生成 POP PDF 文件。

### 1. 填写赛狐流程配置

在“赛狐流程”标签页中填写：

| 配置项 | 说明 |
| --- | --- |
| 赛狐账号 | 赛狐 ERP 登录账号。 |
| 赛狐密码 | 赛狐 ERP 登录密码。 |
| 导出目录 | POP PDF 和 `shipment_ids.json` 的保存目录。 |
| 筛选站点 | 赛狐 FBA 货件筛选站点，例如美国、加拿大。 |
| 筛选店铺 | 店铺主体名，程序会按站点自动拼接后缀，例如 `BPG` + 美国 = `BPG-US`。 |
| 筛选时间 | 更新时间筛选范围，开始时间和结束时间通过日期控件选择。 |
| 模板文件 | POP 生成模板，支持 `.docx` 和 `.pdf`。 |

### 2. 点击开始运行赛狐流程

点击“开始运行赛狐流程”后，程序会自动执行：

1. 登录赛狐 ERP。
2. 进入 FBA 货件页面。
3. 关闭页面公告。
4. 重置筛选条件。
5. 选择站点、店铺、状态和更新时间范围。
6. 抓取存在申收差异的货件编号。
7. 获取货件详情。
8. 基于模板生成 POP PDF。
9. 保存 `shipment_ids.json`。
10. 按需发送邮件。

### 3. 输出结果

赛狐流程完成后，导出目录中会生成：

```text
{店铺名称}_{货件编号}_POP.pdf
shipment_ids.json
```

`shipment_ids.json` 会记录本轮成功生成 POP 的货件编号，易得客流程会优先读取该文件。

## 五、易得客流程使用步骤

易得客流程负责上传材料、提交 CASE 并读取问题编号。

### 1. 填写易得客流程配置

在“易得客流程”标签页中填写：

| 配置项 | 说明 |
| --- | --- |
| 易得客账号 | 易得客登录账号。 |
| 易得客密码 | 易得客登录密码。 |
| 店铺站点 | 影响易得客进店访问的站点。 |
| 店铺 IP | 易得客店铺浏览器 IP。 |
| 店铺端口 | 易得客店铺浏览器调试端口。 |
| Amazon 邮箱 | Amazon Seller Central 登录邮箱；如果浏览器可自动填入，可以保持默认配置。 |
| Amazon 密码 | Amazon Seller Central 登录密码；界面保持星号隐藏。 |
| Amazon 后台站点 | 影响 Seller Central 站点切换和账户选择。 |
| 已完成导出存放 POP 文件的目录 | 赛狐流程生成 POP PDF 和 `shipment_ids.json` 的目录。 |
| 待处理货件编号 | 只展示待处理编号，来源优先为 `shipment_ids.json`，没有时从 POP 文件名兜底提取。 |

### 2. 点击开始运行易得客流程

点击“开始运行易得客流程”后，程序会自动执行：

1. 连接易得客店铺浏览器。
2. 打开 Amazon Seller Central。
3. 登录 Amazon 后台。
4. 切换语言为中文简体。
5. 切换到 GUI 选择的 Amazon 后台站点。
6. 按货件编号进入货件详情页。
7. 读取商品差值。
8. 差值为 0 时跳过当前货件。
9. 差值小于 0 时选择调查缺失商品。
10. 差值大于 0 时选择调查额外商品。
11. 上传当前货件对应的 POP PDF 到交货证明。
12. 上传内置 POD 到库存所有权证明。
13. 点击上传文档并等待上传完成。
14. 点击预览并校验弹窗内容。
15. 校验通过后提交 CASE。
16. 读取 CASE 问题编号。
17. 汇总结果并按配置发送邮件和企业微信通知。

### 3. 上传文件对应关系

| Amazon 页面上传区域 | 上传文件 |
| --- | --- |
| 交货证明 | 当前货件编号对应的 `{店铺名称}_{货件编号}_POP.pdf` |
| 库存所有权证明 | `AWD_POD.pdf` 或 `FBA_POD.pdf` |

POD 文件选择规则：

- 货件创建来源为亚马逊分销时，使用 `AWD_POD.pdf`。
- 货件创建来源为 Send to Amazon 时，使用 `FBA_POD.pdf`。

## 六、邮件和企业微信

### 邮件

开启邮件通知后，程序会按流程发送结果：

- 赛狐流程：发送生成的 POP PDF 附件。
- 易得客流程：发送差异货件编号、CASE 问题编号和相关 POP 文件。

邮件标题和正文使用 UTF-8 编码，避免中文乱码。

### 企业微信

开启企业微信通知后，易得客流程完成时会发送一次汇总消息：

- 汇总成功提交的货件编号。
- 汇总读取到的 CASE 问题编号。
- 汇总失败货件编号和原因。
- 通过手机号 @ 指定人员。

## 七、常见问题

### 1. 没有 POP 文件可以直接跑易得客流程吗？

不建议。易得客流程依赖 POP 文件和货件编号。请先运行赛狐流程生成 POP，再运行易得客流程。

### 2. `run_config.json` 可以删除吗？

可以。删除后程序下次启动会使用 `main.py` 中的默认值回填界面，并在窗口关闭时重新保存。

### 3. `tk_runtime_hook.py` 需要手动运行吗？

不需要。它是 PyInstaller 的运行时钩子，只在打包后的 exe 启动时自动执行，用于修复 `tkinter` / `tkcalendar` 的 Tcl/Tk 资源路径。

### 4. 赛狐页面弹出公告怎么办？

流程会尝试自动关闭公告。若页面公告无法自动关闭，按界面提示人工关闭后继续。

### 5. Word 转 PDF 失败怎么办？

确认电脑已安装 Microsoft Word，并关闭正在打开的模板文件或输出文件。Word 转换异常时，优先检查文件是否被占用。

### 6. 易得客流程某个货件失败怎么办？

程序会记录失败编号并继续处理下一个货件。每个失败货件最后会再重试一次；仍失败时会在结果中提示，需要人工处理。

## 八、打包说明

运行：

```bash
build_exe.bat
```

打包完成后查看：

```text
dist/FBA货件差异自动索赔.exe
```

建议发布整个 `dist` 文件夹。`run_config.json` 会作为用户启动后的默认配置文件一起放在 `dist` 目录中。
