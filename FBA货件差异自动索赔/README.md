# FBA 货件差异自动索赔

本项目用于处理亚马逊 FBA 货件差异索赔流程，当前包含两条独立流程：

- 赛狐流程：从赛狐 ERP 筛选存在差异的 FBA 货件，读取货件明细，并按模板生成 POP 文件。
- 易得客流程：通过易得客店铺环境进入 Amazon Seller Central，按 POP 文件中的货件编号逐个提交索赔材料，并读取 CASE 问题编号。

两个流程在同一个 GUI 中配置和启动，但业务上互相独立。若当前没有 POP 文件，请先运行赛狐流程生成 POP 文件，再运行易得客流程提交索赔。

## 运行环境

- Windows 系统。
- Python 3.12 推荐，当前打包验证环境为 Python 3.12.10。
- 本机需要安装 Chrome 或 Edge，自动化流程通过 DrissionPage 控制浏览器。
- 若需要将 DOCX 转 PDF，本机需要可用的 Microsoft Word。
- 易得客流程依赖本机已安装并可启动的易得客客户端。

## 安装依赖

```bash
pip install -r requirements.txt
```

`requirements.txt` 记录项目运行和打包需要的关键依赖，版本与当前成功打包环境一致。

## 启动方式

```bash
python run.py
```

GUI 中包含两个标签页：

- 赛狐流程：负责生成 POP 文件。
- 易得客流程：负责上传 POD、POP，预览后提交索赔并读取 CASE 编号。

公共配置区包含运行环境、邮件通知、企业微信通知等配置。配置会保存到 `run_config.json`，该文件可删除，程序下次启动会按默认值重新生成。

## 赛狐流程

赛狐流程主要生成索赔所需的 POP 文件，操作内容如下：

1. 登录赛狐 ERP。
2. 进入 FBA 货件页面。
3. 重置页面筛选条件，避免沿用上一次运行残留筛选状态。
4. 选择配置中的站点，例如美国。
5. 按页面条件筛选存在差异的 FBA 货件。
6. 打开货件详情，读取货件编号、店铺、仓库、发货地址、创建时间、SKU、FNSKU、数量等信息。
7. 按货件 SKU 数量选择对应模板生成 DOCX。
8. 将 DOCX 转换为 PDF。
9. 将生成的 POP PDF 保存到 GUI 中配置的导出目录。
10. 如开启邮件发送，则发送生成结果和 POP 附件。

POP 文件命名规则：

```text
{店铺名称}_{货件编号}_POP.pdf
```

## 易得客流程

易得客流程用于进入 Amazon Seller Central 提交索赔材料，操作内容如下：

1. 启动或连接易得客店铺浏览器环境。
2. 按 GUI 中选择的店铺站点访问对应店铺。
3. 登录 Amazon Seller Central。
4. 若当前页面语言不是中文简体，则先切换为中文简体。
5. 若当前 Amazon 站点不是目标站点，则切换到目标站点并选择账户。
6. 从 POP 输出目录读取 `*_POP.pdf` 文件，并从文件名提取货件编号。
7. 按货件编号进入 Amazon 货件详情页。
8. 读取货件商品表格中的差值列。
9. 差值小于 0 时选择“调查缺失商品”。
10. 差值大于 0 时选择“调查额外商品”。
11. 差值全部为 0 时跳过当前货件，并继续处理下一个货件编号。
12. 上传交货证明文件：
    - 亚马逊分销货件上传 `AWD亚马逊分销POD.pdf`。
    - Send to Amazon 货件上传 `FBA直发POD.pdf`。
13. 上传当前货件编号对应的 POP PDF 作为库存所有权证明。
14. 点击“上传文档”，等待按钮不可点击以确认上传完成。
15. 点击预览，校验预览弹窗中的 MSKU、差值、需要操作内容与当前选择的行一致。
16. 预览校验通过后点击提交。
17. 提交后读取页面展示的 CASE 问题编号。
18. 所有本次处理结果汇总后，可发送企业微信通知。

当前测试策略中，可以只跑指定数量的货件编号，用于验证自动切换下一个编号、预览定位和提交按钮定位。

## 邮件与企业微信通知

邮件通知：

- 当前主要用于赛狐流程导出完成后的 POP 文件发送。
- 易得客 CASE 结果邮件发送时，标题和正文使用 UTF-8 编码，避免中文乱码。
- 邮件内容包含差异货件编号、CASE 问题编号和导出的 POP 文件附件。

企业微信通知：

- 使用群机器人 Webhook。
- 支持通过手机号 `mentioned_mobile_list` @ 指定人员。
- 易得客流程结束后汇总发送一次完整结果，不按单个货件重复发送。

## 打包 exe

```bash
build_exe.bat
```

打包产物输出到：

```text
dist/FBA货件差异自动索赔.exe
```

打包脚本会安装 `requirements.txt` 对应的核心依赖，并通过 PyInstaller 按 `FBA货件差异自动索赔.spec` 生成单文件 exe。

已打包进 exe 的资源包括：

- `db53060fa183_发票模板.docx`
- `服务商模板.docx`
- `AWD亚马逊分销POD.pdf`
- `FBA直发POD.pdf`

## 文件职责

| 文件 | 职责 |
| --- | --- |
| `run.py` | 统一 GUI 入口，包含公共配置区、赛狐流程标签页、易得客流程标签页，并负责启动对应流程线程。 |
| `main.py` | 赛狐流程主逻辑，负责登录赛狐、筛选 FBA 货件、读取详情、生成 POP 文件并触发邮件发送。 |
| `auto.py` | 易得客流程主逻辑，负责连接店铺浏览器、切换 Amazon 语言和站点、上传 POD/POP、预览校验、提交索赔并读取 CASE 编号。 |
| `export.py` | POP 文件导出逻辑，负责按模板生成 DOCX、处理单 SKU 和多 SKU 表格样式，并转换 PDF。 |
| `email_util.py` | 邮件发送逻辑，负责 POP 附件发送、CASE 结果邮件发送和中文编码处理。 |
| `wechat.py` | 企业微信机器人通知逻辑，负责汇总消息发送和手机号 @ 人。 |
| `SaihuERPLogin.py` | 赛狐 ERP 登录逻辑，包含验证码 OCR 和登录状态处理。 |
| `YidekeLogin.py` | 易得客客户端与店铺浏览器连接逻辑，负责启动店铺环境并取得调试端口。 |
| `test.py` | 调试测试文件，保留用于局部验证，未确认同步前不作为正式流程入口。 |
| `build_exe.bat` | Windows 打包脚本，负责安装依赖、清理旧产物并调用 PyInstaller。 |
| `FBA货件差异自动索赔.spec` | PyInstaller 打包配置，负责声明入口文件、隐藏导入和内置资源。 |
| `requirements.txt` | 项目运行和打包依赖清单。 |
| `docs/NAMING.md` | 当前子项目代码结构、命名和注释规范。 |
| `run_config.json` | GUI 运行配置缓存文件，可删除后由程序重新生成。 |
| `db53060fa183_发票模板.docx` | 单 SKU POP 生成模板。 |
| `服务商模板.docx` | 多 SKU POP 生成模板。 |
| `AWD亚马逊分销POD.pdf` | 亚马逊分销货件使用的交货证明文件。 |
| `FBA直发POD.pdf` | Send to Amazon 货件使用的交货证明文件。 |

## 注意事项

- 不要在 Word 中打开模板或输出文件时同时运行导出流程，否则可能因为文件锁导致 DOCX 或 PDF 生成失败。
- PowerShell 中直接传递中文字符串时可能出现编码问题，涉及中文内容建议通过文件读取或程序内部固定文本处理。
- 易得客流程按 POP 文件名提取货件编号，因此 POP 文件命名必须保留货件编号。
- 邮件发送和企业微信发送均为可选项，建议先在测试货件中确认结果内容后再正式批量运行。
