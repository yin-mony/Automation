# Transaction 报告流程使用说明

## 1. 流程用途

本流程通过易得客启动指定店铺浏览器，进入 Amazon Seller Central，
按顺序切换一个或多个后台站点，并为每个站点请求上一个自然月的
Transaction 报告。

流程以成功点击“请求报告 / Request Report”为完成条件，不会持续等待
Amazon 生成报告，也不会自动点击报告列表中的下载按钮。

## 2. 运行前准备

运行前请确认：

1. 当前电脑为 Windows，并且易得客客户端可以正常启动。
2. Python 3 已安装。
3. 已安装项目依赖：

   ```powershell
   pip install DrissionPage psutil pywinauto python-dateutil
   ```

4. 易得客账号、密码、店铺 IP 和店铺端口可用。
5. 店铺浏览器中已有可用的 Amazon 登录状态；如果没有，需要准备
   Amazon 邮箱、密码以及二步验证码。
6. 当前系统日期和时间正确。报告月份由系统时间自动计算。

## 3. 启动 GUI

在 PowerShell 中进入项目目录：

```powershell
cd C:\Users\admin\Desktop\Automation\下载美国站Transaction报告
python run.py
```

打开后先核对配置，再点击“开始请求 Transaction 报告”。

## 4. GUI 配置说明

### 4.1 公共配置

| 配置项 | 填写说明 |
| --- | --- |
| 运行环境 | “线下”和“线上”只用于区分 GUI 与日志标识。两种模式都会先登录易得客、访问店铺，再执行 Amazon 后台流程。 |
| 邮件通知 | 选择“不发送”时只执行报告请求；选择“发送”时，流程结束后尝试发送本地已有的报告文件。 |
| 接收邮箱 | 仅在邮件通知选择“发送”时必填。 |

### 4.2 易得客流程配置

| 配置项 | 填写说明 |
| --- | --- |
| 易得客账号 | 用于登录易得客工作台。 |
| 易得客密码 | 与易得客账号配套使用，可通过“显示/隐藏”按钮检查。 |
| 店铺站点 | 易得客工作台中的店铺所属站点，只能选择一个，用于定位店铺访问入口。 |
| 店铺 IP | 需要访问的易得客店铺 IP。 |
| 店铺端口 | 易得客浏览器远程调试端口。 |
| Amazon 邮箱 | 可留空。留空时优先使用易得客浏览器中已有的 Amazon 登录状态。 |
| Amazon 密码 | 可留空。需要重新登录 Amazon 时再填写。 |
| Amazon 后台站点 | 使用复选框多选。流程按照界面中的站点顺序逐个切换并请求报告。 |

### 4.3 两种站点的区别

- **店铺站点**：易得客入口站点，只能选择一个，用于在易得客工作台中
  找到并访问对应店铺。
- **Amazon 后台站点**：Seller Central 内部站点，可以选择多个。
  进入店铺后，流程会自动逐站切换并执行报告请求。

例如，店铺入口位于美国区域，但需要请求美国、加拿大和墨西哥报告时：

```text
店铺站点：美国
Amazon 后台站点：勾选 美国、加拿大、墨西哥
```

## 5. 自动执行步骤

点击“开始请求 Transaction 报告”后，流程按以下顺序运行：

1. 校验 GUI 必填配置以及 Amazon 后台站点选择。
2. 登录易得客工作台。
3. 根据店铺站点和店铺 IP 定位店铺，并点击访问店铺。
4. 启动或接管易得客浏览器，等待 Seller Central 页面打开。
5. 检查 Amazon 当前页面：
   - 邮箱登录页
   - 密码输入页
   - 账户或店铺选择页
   - 二步验证码页
6. 检查 Seller Central 界面语言：
   - 已是中文简体时不切换
   - 检测为英文时切换为中文简体
7. 根据当前系统日期计算上一个自然月和对应年份。
8. 按复选框顺序切换到第一个 Amazon 后台站点。
9. 打开“付款 / Payments”并进入报告库。
10. 检查筛选项数量、当前值以及是否可点击。
11. 选择 Transaction 报告、月度日期范围、上一个自然月和对应年份。
12. 点击“请求报告 / Request Report”。
13. 切换到下一个已选择站点并重复报告请求。
14. 所有站点完成后结束流程；启用邮件时再执行附件发送。

## 6. 报告月份规则

报告月份固定为当前系统月份减去一个月，即上一个自然月。

示例：

| 当前系统日期 | 自动选择的报告月份 |
| --- | --- |
| 2026 年 7 月 31 日 | 2026 年 6 月 |
| 2026 年 1 月 10 日 | 2025 年 12 月 |

如果页面最终显示的月份不正确，请先检查电脑的系统日期、时间和时区。

## 7. 不同站点的筛选规则

### 美国站

美国站在月份选择前通常有 3 个筛选：

1. 商城：选择“所有商城 / All Stores”。
2. 账户类型：优先选择“全部 / All”。
3. 报告类型：选择“交易 / Transaction”。

### 其他站点

加拿大、墨西哥、巴西等其他站点通常只有 2 个筛选：

1. 账户类型：优先选择“全部 / All”。
2. 报告类型：选择“交易 / Transaction”。

每个筛选都会先检查当前值和可点击状态：

- 当前值已经正确时不重复点击。
- 控件不可点击但当前值正确时继续。
- 控件不可点击且当前值错误时停止当前流程，避免请求错误报告。
- 账户类型没有“全部 / All”选项时，保留当前站点已有的有效值。

## 8. Amazon 登录页面处理

### 已保持登录

如果易得客浏览器已保存 Amazon 登录状态，Amazon 邮箱和密码可以留空，
流程会直接检查账户及站点后继续。

### 需要重新登录

如果页面停留在 Amazon 登录页：

1. 流程会识别邮箱页和密码页。
2. 已在 GUI 填写 Amazon 邮箱和密码时，流程会尝试继续登录。
3. 出现二步验证时，需要在浏览器中人工完成验证码。
4. 完成后不要关闭浏览器，流程会继续等待 Seller Central 页面。

## 9. 邮件通知

邮件通知不会等待 Amazon 报告生成或自动下载报告。

选择“发送”后，流程结束时会在报告目录中查找文件名包含
`下载美国站Transaction报告` 的现有文件，并将找到的文件作为附件发送。
默认报告目录是当前 Windows 用户的桌面。

SMTP 发件信息可通过 PowerShell 环境变量提供：

```powershell
$env:SMTP_SENDER = "发件邮箱"
$env:SMTP_AUTH_CODE = "SMTP 授权码"
python run.py
```

如果没有找到符合名称规则的文件，邮件不会发送附件。

## 10. 命令行调用

也可以在代码中传入配置运行：

```python
from main import TestPage

config = {
    "username": "易得客账号",
    "password": "易得客密码",
    "ip": ["店铺 IP"],
    "port": [9527],
    "autoSiteName": "美国",
    "amazonSiteNames": ["美国", "加拿大", "墨西哥"],
    "amazonEmail": "",
    "amazonPassword": "",
    "isOnline": False,
    "sendEmail": False,
    "email": "",
}

TestPage(config).run()
```

易得客账号和密码也可以使用环境变量：

```powershell
$env:YIDEKE_USERNAME = "易得客账号"
$env:YIDEKE_PASSWORD = "易得客密码"
python run.py
```

## 11. 运行日志

GUI 下方的“Transaction 运行日志”会显示：

- 易得客登录和店铺访问状态
- 浏览器启动及调试端口状态
- Amazon 登录页面检查结果
- 当前 Amazon 后台站点
- 报告筛选数量和可点击状态
- 本次请求的年份与月份
- 每个站点的请求结果
- 邮件发送结果

流程失败时，请先保留日志中最后一段错误信息，再检查对应步骤。

## 12. 常见问题

### 易得客页面提示网络出口错误

1. 在易得客设置中打开高级网络模式。
2. 检查店铺 IP、网络出口和代理配置。
3. 回到店铺页面重新检测。
4. 确认 GUI 中填写的店铺 IP 与目标店铺一致。

该问题属于易得客环境检测失败，不是 Seller Central 报告筛选问题。

### 店铺连接失败或调试端口不可用

1. 确认店铺 IP 和端口填写正确。
2. 确认易得客客户端没有卡在环境检测页。
3. 关闭该店铺残留的异常浏览器后重试。
4. 检查端口是否被其他程序占用。

### Amazon 一直停留在登录页

1. 检查 Amazon 邮箱和密码。
2. 查看是否出现验证码或二步验证。
3. 手动完成验证后保持浏览器打开。
4. 确认选择了正确的 Seller Central 账户。

### 站点切换失败

1. 确认目标站点已在当前 Amazon 账户中开通。
2. 查看页面是否出现“查看所有 / See all”。
3. 确认 GUI 中“店铺站点”和“Amazon 后台站点”没有混淆。

### 筛选数量异常

1. 先确认当前 Amazon 后台站点是否正确。
2. 美国站应有 3 个筛选，其他站点通常为 2 个。
3. 如果 Amazon 更新了页面结构，请保留截图和运行日志后再调整定位。

### 页面月份不是上个月

1. 检查 Windows 系统日期、时间和时区。
2. 查看日志中的“本次请求报告月份”。
3. 确认页面年份与月份都已完成切换。

## 13. 打包 EXE

执行：

```powershell
build_exe.bat
```

或者：

```powershell
pyinstaller --clean 下载美国站Transaction报告.spec
```

打包完成后，生成文件位于 `dist` 目录。

## 14. 使用注意事项

- 运行期间不要关闭易得客或正在执行的 Seller Central 浏览器。
- 不要在自动点击期间手动切换 Amazon 站点或修改报告筛选。
- 多站点执行时间会随站点数量增加。
- Amazon 页面结构变更后，原有元素定位可能需要同步调整。
- 不要将真实账号、密码或 SMTP 授权码写入说明文档、提交记录或截图。
